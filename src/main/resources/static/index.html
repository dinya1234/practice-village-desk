Диспетчерская посёлка

Звонки имитируются кнопками, жители и линии вымышлены. Данные общие для обеих смен.

Звонки имитируются кнопками. Линии не являются телефонными номерами. Данные хранятся на локальном сервере и видны обеим сменам.
