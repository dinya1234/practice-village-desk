# Работа над практикой

Пишите по-русски. Сначала разберитесь с данными и сценариями в README. Работайте с вымышленными записями и имитацией звонков; никаких реальных номеров, ключей и внешних сервисов. Решения по экранам принимает команда студентов. После изменений проверьте оба сценария из README и запуск по своей инструкции.
